## 개발 환경

사이트는 Astro와 Starlight를 사용하여 정적 파일로 빌드한다. Node.js 22.12.0 이상과 npm 9.6.5 이상이 필요하다.

```shell
npm install
npm run dev
```

정적 빌드와 빌드 결과 미리보기는 다음 명령을 사용한다.

```shell
npm run build
npm run preview
```
