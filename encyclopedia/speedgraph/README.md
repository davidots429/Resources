## 초록

도로 센서의 교통 속도는 시간적 변화와 도로망의 공간적 관계에 동시에 영향을 받는다. 본 연구는 시공간 그래프 합성곱 신경망(Spatio-Temporal Graph Convolutional Network, STGCN)을 **과거 12개 5분 시점에서 미래 12개 시점의 속도를 한 번에 출력하는 문제**에 맞춰 재설계하고, 두 독립적인 교통 데이터셋 METR-LA와 PeMSD4에서 검증하였다. 센서별 입력은 학습 구간의 원관측 속도로 표준화한 값, 하루 중 5분 슬롯의 학습 임베딩, 요일 임베딩, 원관측 여부를 나타내는 마스크로 구성한다. 두 시간–공간–시간 블록에는 희소 Chebyshev 그래프 특징의 공유 투영, 시간층별 입력 잔차, 공간 입력 잔차, 노드·채널 정규화와 직접 다중 시점 출력층을 적용했다.

각 데이터셋을 독립적으로 학습한 세 난수 초기화의 시험 결과에서 최종 모델의 전체 12시점 평균절대오차는 METR-LA **3.052393 ± 0.000805**, PeMSD4 **1.516887 ± 0.001898**이었다. 같은 예측 과제에 맞춰 수정한 STGCN 기준 모델에 비해 각각 **4.58%**, **6.73%** 낮았다. 마지막 예측 시점의 오차 감소율은 각각 **7.92%**, **9.96%**였다. 속도만 쓰는 동일 기본 구조에서 노드·채널 정규화 구성을 적용한 통제 실험도 두 데이터셋에서 개선 방향을 보였다. 다만 최종 모델과 기준 모델의 차이는 여러 설계 선택을 함께 포함하므로 개별 요소의 독립적인 인과 효과로 해석하지 않는다.

연구 과정에서 Receiver MoE도 검토했으나 일관된 예측 우위가 확인되지 않아 최종 모델에 포함하지 않았다. 최종 결과의 의의는 직접 다중 시점 예측에 맞춘 STGCN 구성과, 결측·그래프·분할·체크포인트·평가 절차를 분리하여 재현 가능한 비교를 수행했다는 데 있다.

**주제어:** 교통 속도 예측, 다중 시점 예측, 시공간 그래프 합성곱 신경망, 결측 마스크, 노드·채널 정규화
