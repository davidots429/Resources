## 한눈에 보기

이 기능은 검증된 조리결과와 평가를 학습데이터로 선별하고, 반복 조리의 차이와 실패요인을 분석하여 레시피 개선안을 만드는 기능이다. 개선안은 자동 반영하지 않고 사람이 승인한 뒤 새 레시피 버전으로 등록한다.

## 왜 이렇게 정했는가

품질이 낮거나 출처를 추적할 수 없는 데이터를 학습에 포함하면 개선이 아니라 오류를 반복할 수 있다. 또한 좋은 결과가 한 번 나왔다고 해서 원인이 특정 설정값 때문이라고 단정할 수 없다.

그래서 학습 후보에 엄격한 품질 게이트를 적용하고, 표본이 부족하면 분석 한계를 표시한다. AI가 제시한 개선은 후보일 뿐이며 승인 전에는 원본 레시피를 바꾸지 않는다.

## 무엇을 하는가

- 조리결과, 평가, 권장값과 실제값을 학습 후보로 연결한다.
- 품질 상태, Null과 중복을 검사한다.
- 포함·제외 결과와 이유를 기록한다.
- 데이터셋, 모델, 프롬프트와 학습조건의 버전을 관리한다.
- 반복 조리의 차이와 실패요인을 분석한다.
- 개선 후보, 기대 영향과 제한사항을 제시한다.
- 승인된 개선안을 새 레시피 버전으로 등록한다.

## 어떻게 동작하는가

1. [데이터 품질 검증과 보정 이력](data-quality.md)을 통과한 조리 데이터를 모은다.
2. 경고 이력, 격리 상태, 핵심 Null과 중복을 검사한다.
3. 통과한 레코드로 불변 데이터셋 버전을 만든다.
4. 비교할 메뉴, 레시피 버전과 지표를 선택한다.
5. 결과 차이와 실패요인을 분석해 개선안을 생성한다.
6. 레시피 담당자가 검토·승인하면 새 버전으로 등록한다.

## 예외와 경계

- 경고 이력이 있거나 격리된 데이터는 학습 후보에 포함하지 않는다.
- 결측치 추정으로 품질 게이트를 우회하지 않는다.
- 표본이 부족한 결과를 확정 개선안으로 표시하지 않는다.
- 개선안이 기존 레시피를 자동 변경하지 않는다.
- 모델 재학습 방식과 배포 절차는 설계에서 별도로 정한다.

## 현재 결정

학습 후보는 품질 이력에 경고가 없고 현재 정상이며, 핵심 Feature와 Label에 Null이 없고 승인된 식별자나 해시로 중복 제거된 데이터만 포함한다. 데이터셋과 생성 조건은 재현 가능한 버전으로 관리한다.

핵심 컬럼 목록, 자동 보정 데이터의 학습 허용 여부, 개선효과 지표와 Golden Dataset의 평가척도는 설계 단계에서 확정한다.
