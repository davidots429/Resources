## 한눈에 보기

매장 프로파일은 업종, 주요 메뉴, 보유 장비, 목표원가, 운영시간, 조리인원, 선호와 제약을 매장별로 관리하는 기능이다. 추천과 검색은 이 정보를 공통 조건으로 사용한다.

## 왜 이렇게 정했는가

같은 레시피도 매장의 장비, 인력과 운영 목표에 따라 적합성이 달라진다. 사용자가 요청할 때마다 모든 조건을 다시 입력하게 하면 누락과 불일치가 생기고, 여러 매장의 데이터가 섞이면 정보 노출 위험도 커진다.

그래서 반복되는 현장 조건은 버전이 있는 매장 프로파일로 관리하고, 추천과 분석에 일관되게 적용한다. 입력되지 않은 값은 그럴듯한 기본값으로 채우지 않고 미설정 상태로 유지한다.

## 무엇을 하는가

- 매장의 기본정보와 업종을 관리한다.
- 주요 메뉴와 보유 장비를 연결한다.
- 목표원가, 운영시간과 조리인원을 기록한다.
- 선호, 알레르기와 운영 제약을 관리한다.
- 프로파일 변경 이력을 보존한다.
- 추천 요청에 적용된 프로파일 버전을 연결한다.

## 어떻게 동작하는가

1. 매장 소유자나 관리자가 기본정보를 등록한다.
2. 장비, 메뉴와 운영조건을 연결한다.
3. 필수값, 범위와 변경 권한을 확인한다.
4. 변경 시 새 프로파일 버전을 저장한다.
5. [조건 기반 메뉴와 레시피 추천](recipe-recommendation.md)이 현재 프로파일을 읽는다.
6. 추천 결과에 적용한 조건과 미설정 항목을 표시한다.

## 예외와 경계

- 미입력 항목을 임의의 기본값으로 추정하지 않는다.
- 다른 매장의 프로파일을 조회하거나 변경하지 못하게 한다.
- 프로파일 변경이 이미 완료된 과거 추천의 조건을 바꾸지 않는다.
- 자유의견에 개인정보나 민감정보를 입력하지 않도록 안내한다.
- 원가와 영양 기준 데이터가 없으면 계산 결과를 확정값으로 표시하지 않는다.

## 현재 결정

매장 프로파일은 추천, 검색과 장비 활용 시나리오의 공통 입력으로 사용한다. 매장별 접근 격리를 적용하고 변경 버전을 유지한다.

필수 필드, 기본 제공 값, 프로파일 승인 절차와 여러 매장을 가진 사용자의 전환 방식은 설계 단계에서 확정한다.
