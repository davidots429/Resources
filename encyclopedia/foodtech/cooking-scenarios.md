## 한눈에 보기

대표 조리 시나리오는 돈까스·튀김기, 제육볶음·볶음교반기, 고등어구이 정식·콤비오븐의 조리 흐름을 사용해 수집부터 판정, 평가와 AI 권고 검토까지 연결한다. 모든 장비와 수치는 개인 프로젝트의 합성 시나리오이며 실제 제조사 사양, 범용 조리법 또는 법정 안전기준을 뜻하지 않는다.

## 왜 이렇게 정했는가

장비 상태나 데이터 필드만 따로 시험하면 조리 중 어떤 시점에 값이 필요하고, 결손과 운영자 입력이 최종 판정에 어떤 영향을 주는지 확인하기 어렵다. 반대로 실제 장비와 현장 없이 일반적인 조리법을 사실처럼 작성하면 검증할 수 없는 가정이 된다.

그래서 장비 유형마다 대표 메뉴를 하나씩 정하고, 합성 조건과 예외를 명시한 종단간 시나리오로 만든다. 세 시나리오는 공통 4단계 화면 흐름을 사용하되 메뉴별 단계, 센서와 판정은 서로 다르게 유지한다.

## 공통 흐름

1. 준비·예열에서 메뉴, 레시피 버전, 장비, 배치와 시작조건을 확인한다.
2. 투입·모니터링에서 장비 시계열과 운영자 사건을 함께 기록한다.
3. 인양·평가에서 공정 자동판정, 식품 안전과 품질평가를 분리해 확정한다.
4. AI 권고 검토에서 변경 전·후 값, 제약, 데이터 완전성과 판단 불가 사유를 확인한다.

AI 권고는 장비에 자동 적용하지 않는다. 승인하더라도 기존 레시피를 덮어쓰지 않고 새 후보 레시피 버전으로 만든다.

## 돈까스와 튀김기

돈까스는 냉장 비분쇄 통등심 생제품을 합성 튀김기로 조리하는 시나리오다. 두께 프로파일을 선택하고 배치중량, 기름 온도, 투입·인양시각과 심부온도를 기록한다.

| 항목 | 현재 합성 기준 |
| --- | --- |
| 정상 기름 온도 | `165~175°C`, 목표 `170°C` |
| 두께 프로파일 | Thin `0.5~1.0cm`, Standard `1.0~1.5cm`, Thick `1.5~2.0cm` |
| 목표시간 | Thin `180초`, Standard `300초`, Thick `360초` |
| 목표 배치중량 | `2.4kg`, 허용 `2.3~2.5kg` |
| 안전 확인 | 심부온도 `75°C 이상`을 `60초` 유지 |

투입 뒤 온도가 `165°C`로 회복되는 시간과 저온·고온 이탈의 지속시간을 따로 계산한다. 인양시각과 화면에 완료를 기록한 시각도 분리한다. 데이터가 부족하거나 안전 측정이 무효하면 AI는 보정값을 만들지 않고 판단 불가를 반환한다.

## 제육볶음과 볶음교반기

제육볶음은 소형·중형·대형 장비에서 고기, 채소와 소스를 순서대로 투입하고 솥 표면온도, 혼합물 온도, 교반축 RPM, 모터 부하와 배출 구간을 관찰하는 시나리오다.

| 규모 | 목표 투입량 | 목표 표면온도 | 목표 교반속도 | 목표 조리시간 |
| --- | ---: | ---: | ---: | ---: |
| 소형 | `1.8kg` | `200°C` | `30rpm` | `480초` |
| 중형 | `12.0kg` | `180°C` | `20rpm` | `900초` |
| 대형 | `60.0kg` | `160°C` | `10rpm` | `1,500초` |

고기, 채소와 소스는 별도 투입사건으로 남긴다. 조리시간은 고기 투입 완료부터 배출 시작까지이며, 전체 공정시간과 배출 완료는 별도 값이다. 목표 RPM이 0인 의도적 정지는 교반 이상으로 보지 않는다. 목표 RPM이 있는데 저속과 90% 초과 모터 부하가 함께 5초 지속되면 걸림 경고, 30초 지속되면 교반 실패로 판정한다.

안전은 혼합물의 승인된 최저온도 위치가 `75°C 이상`을 `60초` 유지하는지 매 배치 확인한다. 남은 RPM 지속시간, 접촉간극 판정값과 실행용 안전 시계열은 구현 전 추가 확정한다.

## 고등어구이 정식과 콤비오븐

이 시나리오는 정식 전체가 아니라 콤비오븐에서 수행하는 밥 스팀 조리와 고등어 건열 굽기만 다룬다. 두 작업은 하나의 식사 배치로 연결하지만 서로 다른 조리작업, 프로그램과 판정을 가진다.

| 항목 | 밥 | 고등어 |
| --- | ---: | ---: |
| 조리 모드 | `STEAM` | `DRY_HEAT` |
| 목표 챔버 온도 | `100°C` | `220°C` |
| 기후 설정 | `100%` | `10%` |
| 목표시간 | `1,800초` | `720초` |
| 팬 단계 | `4` | `3` |

기본 흐름은 밥 조리·인양, 챔버 건조와 모드 전환, 고등어 투입·조리 순서다. 기후 설정값은 장비 설정이며 실제 상대습도와 같다고 보지 않는다. 실제 습도 센서가 없으면 전환 뒤 최소 180초, 온도 `215~225°C` 30초 유지, 문 닫힘과 무알람 같은 대체 근거를 사용한다.

고등어 안전평가는 랙과 팬 위치를 대표하는 표본을 교정된 탐침으로 동시에 측정하고, 전체 60초 시계열의 최저값이 모두 `75°C 이상`이어야 통과한다. 밥과 고등어를 같은 챔버에서 동시에 조리하지 않으며, 모드 전환이 완료되지 않으면 고등어 투입을 허용하지 않는다.

## 공통 예외와 판정

- `DATA_GAP`, `SENSOR_LOST`, 완료 미기록과 평가 미완료를 구분한다.
- 공정, 안전, 품질과 AI 권고 상태는 별도로 저장한다.
- 수동 변경은 원 판정을 덮어쓰지 않고 변경 전·후 값과 사유를 기록한다.
- 안전 실패 뒤 추가 가열은 새 공정 구간과 새 안전평가로 남긴다.
- 장비 제어, 자동 정지와 프로그램 자동 배포는 범위 밖이다.
- 품질평가 척도, 반복횟수, 참가 역할과 전체 통과기준은 테스트 계획 전에 확정한다.

## 현재 결정

세 대표 메뉴와 장비 유형, 합성 공정조건, 공정·안전·품질·AI 판정의 분리와 주요 예외는 승인됐다. 메뉴별 상세 화면·시퀀스, 실제 Mapping ID, 실행 fixture와 반복·합격 기준은 각각 설계, Mock 구현과 테스트 계획 단계에서 확정한다.
