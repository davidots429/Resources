---
title: 조리결과와 운영성과 분석
---

운영성과 분석은 메뉴, 레시피, 장비와 기간별로 조리시간, 성공률, 장비 가동률, 품질, 재료·에너지 사용량, 장애와 권장값 대비 실제값을 비교하는 기능이다. 화면과 다운로드 결과에 같은 계산 기준을 적용한다.

집계값만 보여주고 분모, 제외조건과 데이터 품질을 숨기면 같은 지표도 사람마다 다르게 해석할 수 있다. 데이터가 없을 때 0으로 표시하면 실제 성과가 0인 경우와 수집이 실패한 경우도 구분되지 않는다.[^basis]

그래서 모든 지표에 포함·제외 기준과 데이터 버전을 적용하고, 데이터 없음과 품질 미달을 명확히 표시한다. 레시피 개선 전후를 비교할 때도 같은 메뉴와 조건을 가진 집단인지 확인한다.

## 운영·품질 지표

- 메뉴, 레시피, 장비, 매장과 기간으로 분석 범위를 선택한다.
- 조리시간과 성공·실패 현황을 집계한다.
- 장비 가동률과 장애 빈도를 계산한다.
- 품질평가와 재조리 현황을 비교한다.
- 재료·에너지 사용량과 권장·실제값 편차를 분석한다.
- 개선 전후 결과를 비교한다.
- 표, 그래프와 다운로드 데이터를 제공한다.

## 집계와 비교

1. 사용자의 권한과 매장 범위를 확인한다.
2. 선택한 기간과 데이터 버전에 맞는 유효 데이터를 조회한다.
3. 지표별 분자, 분모와 제외조건을 적용한다.
4. 제외건수와 데이터 품질 상태를 함께 계산한다.
5. 화면과 다운로드에 같은 집계 결과를 제공한다.
6. 개선 판단이 필요하면 [학습데이터 검토와 레시피 개선](../ai/learning-data-improvement.md)으로 연결한다.

## 실패와 책임 경계

- 데이터가 없거나 품질 기준을 충족하지 않으면 0으로 대체하지 않는다.
- 서로 다른 레시피 버전과 평가척도를 무조건 같은 집단으로 합치지 않는다.
- 권한 밖 매장의 집계 원문을 노출하지 않는다.
- 지표 상관관계를 원인으로 단정하지 않는다.
- 분석 결과가 레시피나 장비 설정을 자동 변경하지 않는다.

## 설계 상태와 남은 작업

공정 완료율은 `정상완료 작업 ÷ 시작 작업`, 안전 실패율은 `안전 실패 작업 ÷ 안전판정 완료 작업`처럼 지표마다 분자와 분모를 명시한다. 공정·안전·품질·AI 권고 상태를 하나의 성공률로 합치지 않는다. 메뉴, 장비 유형, 조리량, 레시피·평가척도 버전과 기간을 공통 분석 차원으로 사용한다. 분모가 0이거나 필수 입력이 누락되면 값 0이 아니라 `미산출`로 표시한다.[^analytics]

정상 수집 규모와 화면 응답 목표는 정해져 있지만, 동시 사용자 수와 화면별 상세 성능기준은 테스트 계획과 함께 구체화한다.

분석 진입점은 `SCR-401`이며 권한 범위 안에서 지표와 함께 표본 수·제외 건수·산식 버전을 보여준다. 재계산은 과거 결과를 덮지 않고 새 집계 버전을 만든다. 지표별 운영 목표값, 최소 비교 표본, 통계 기준과 실제 부하 기준선은 대표 데이터와 시험 뒤 확정한다.
