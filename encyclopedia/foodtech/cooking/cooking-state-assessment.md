---
title: 조리작업 단계·상태와 판정 체계
---

조리작업은 준비·예열, 투입·모니터링, 인양·평가, AI 권고 검토의 네 화면 흐름으로 진행한다. 작업 진행상태와 공정 자동판정, 식품 안전판정, 품질평가, AI 권고 검토상태는 서로 다른 의미이므로 하나의 합격 여부로 합치지 않는다.

조리가 끝났다는 사실은 공정조건이 정상이고 식품이 안전하며 품질평가와 AI 검토까지 완료됐다는 뜻이 아니다. 이 상태들을 하나로 합치면 센서 결손 때문에 공정판정이 제한된 경우와 운영자가 품질평가를 아직 입력하지 않은 경우를 구분할 수 없다.[^basis]

그래서 작업의 진행상태는 실제 업무 흐름만 나타내고, 각 판정은 별도 결과와 사유를 가진다. 이 분리는 화면에서 사용자가 다음 행동을 판단하게 하고, 나중에 원인을 분석할 때 어떤 판단이 언제 바뀌었는지 재현하게 한다.

## 작업 상태와 판정

- 조리작업과 프로그램 단계의 현재상태를 관리한다.
- 상태가 바뀐 사건, 주체, 시각과 사유를 기록한다.
- 공정조건, 안전, 품질과 AI 권고 검토를 따로 표시한다.
- 자동판정을 사람이 변경하면 원 판정과 변경 이력을 함께 보존한다.
- 일시정지, 재개, 실패, 취소와 평가 미완료를 구분한다.
- 데이터 결손과 센서 상실이 판정에 미치는 영향을 보여준다.

## 작업과 단계 상태

조리작업은 `PENDING ↔ READY → RUNNING ↔ PAUSED → COMPLETED/FAILED/CANCELED` 흐름을 기준으로 한다. 준비조건이 사라지면 `READY`에서 `PENDING`으로 돌아갈 수 있고, 명시적인 재개 사건이 있어야 `PAUSED`에서 `RUNNING`으로 돌아간다.

프로그램 단계는 `PENDING`, `ACTIVE`, `COMPLETED`, `SKIPPED`, `CANCELED`, `FAILED`를 사용한다. 작업과 단계 상태를 분리하는 이유는 하나의 작업 안에서 일부 단계가 실패하거나 생략되어도 작업 전체의 종료 사유와 후속 평가 가능성을 따로 판단해야 하기 때문이다.

## 판정 체계

| 구분 | 답하는 질문 | 예시 |
| --- | --- | --- |
| 작업 상태 | 조리는 지금 어느 단계인가 | `RUNNING`, `PAUSED`, `COMPLETED` |
| 공정 자동판정 | 시간·온도·속도 등 공정조건이 기준에 맞았는가 | 정상, 경고, 실패, 적용 불가 |
| 식품 안전판정 | 유효한 안전 측정이 기준을 충족했는가 | 통과, 실패, 미측정, 무효값 |
| 품질평가 | 완성품의 맛·식감·외관 등은 어떠한가 | 평가 결과와 복수 사유 |
| AI 권고 검토 | 후보 권고를 운영자가 채택했는가 | `PENDING`, `ACCEPTED`, `REJECTED` |

평가가 끝나지 않은 상태는 작업을 다시 `RUNNING`으로 되돌리지 않고 `ASSESSMENT_INCOMPLETE` 같은 별도 판정으로 표현한다. 자동판정 변경도 원 결과를 덮어쓰지 않고 변경 전·후 값, 사유, 주체와 시각을 추가 이력으로 남긴다.

## 화면 흐름

1. `SCR-101`에서 메뉴, 레시피, 장비와 배치 조건을 선택하고 준비상태를 확인한다.
2. `SCR-102`에서 시계열, 단계 상태와 운영자 사건을 보며 투입·모니터링한다.
3. `SCR-103`에서 인양시각과 완료기록 시각을 구분하고 공정·안전·품질 결과를 입력한다.
4. `SCR-104`에서 후보 레시피의 변경점, 근거, 제약과 데이터 완전성을 확인하고 권고를 검토한다.

오류·경고·안내 메시지는 원인, 영향, 다음 행동과 추적 ID를 함께 보여준다. 대기, 빈 상태, 부분 데이터, `STALE`, `OFFLINE`과 권한 없음도 서로 다른 화면 상태로 표시한다.

## 실패와 책임 경계

- `DATA_GAP`은 조리작업의 실패와 같지 않지만, 해당 구간의 공정판정을 제한할 수 있다.
- 5초 수집주기에서 30초 연속 결손이 발생하면 `SENSOR_LOST`와 `DISCONNECTED`로 확정한다.
- 플랫폼의 일시정지·취소 기록은 장비를 물리적으로 정지시키는 제어 명령이 아니다.
- 실패나 취소 뒤 어떤 평가를 허용할지, 메뉴별로 어디까지 복귀할지는 시나리오 설계에서 확정한다.
- 품질평가는 승인된 일곱 항목 1~5점 척도와 종합점수 산식을 사용한다. 메뉴별 세부 관찰 기준과 예외는 별도 확정한다.

## 설계 상태와 남은 작업

작업과 단계 상태, 네 판정의 분리, 수동 변경의 추가 이력, 4단계 화면 흐름은 현재 설계 기준이다. 일곱 항목의 1~5점 품질평가와 종합점수 산식도 현재 기준이며 [품질평가](cooking-quality-evaluation.md)에서 설명한다. 메뉴별 중단·재개·오류 복귀, 역할별 세부 행동권한과 메뉴·장비별 관찰 기준은 관련 설계와 테스트 계획 전에 확정한다.
