## 한눈에 보기

레시피 질의응답은 사용자가 레시피의 단계, 장비 사용법, 권장조건과 주의사항을 자연어로 질문하고 설명을 받는 기능이다. 답변은 사용자가 접근할 수 있는 승인 데이터와 허용된 참고정보 범위에서 생성한다.

## 왜 이렇게 정했는가

구조화된 레시피만으로는 특정 단계가 필요한 이유나 현재 장비에서 어떻게 적용해야 하는지 이해하기 어려울 수 있다. 자연어 설명은 현장 사용성을 높이지만, 근거가 부족한 답을 단정하거나 다른 매장의 비공개 정보를 포함하면 안 된다.

그래서 질문할 때 현재 레시피, 장비와 매장 범위를 함께 적용하고, 답변의 한계와 주의사항을 표시한다. 답변은 설명을 돕는 기능이며 승인된 레시피나 안전 절차를 대체하지 않는다.

## 무엇을 하는가

- 사용자의 질문 의도와 현재 업무 맥락을 파악한다.
- 승인된 레시피와 접근 가능한 매장·장비 정보를 검색한다.
- 단계별 설명, 적용 방법과 주의사항을 생성한다.
- 참고한 레시피와 데이터 범위를 내부적으로 연결한다.
- 근거가 부족하거나 답할 수 없는 질문을 구분한다.
- 답변과 사용자 피드백을 기록한다.

## 어떻게 동작하는가

1. 사용자의 역할과 매장 범위를 확인한다.
2. 질문을 레시피, 조리방법, 장비, 주의사항 등으로 분류한다.
3. 접근 가능한 승인 데이터만 검색한다.
4. AI가 답변을 생성하고 제한사항을 덧붙인다.
5. 응답을 안전·권한 규칙으로 다시 확인한 뒤 표시한다.
6. 필요하면 관련 레시피와 [장비 적합성 기반 권장 조리조건](recommended-cooking-conditions.md)으로 연결한다.

## 예외와 경계

- 근거가 부족한 안전 관련 질문에 단정적으로 답하지 않는다.
- 미승인 레시피를 일반 사용자 답변에 사용하지 않는다.
- 다른 매장의 비공개 정보와 개인정보를 포함하지 않는다.
- AI 장애 시 대체 응답이라는 사실을 숨기지 않는다.
- 답변만으로 장비를 제어하거나 레시피 상태를 변경하지 않는다.

## 현재 결정

단순 질의응답에는 Gemini 3.8 Flash를 사용하고 timeout은 15초다. 개발은 `v1beta`, 운영은 `v1` API 경로를 사용한다. 모델과 API 경로의 구조화 출력 지원 여부는 각 환경에서 검증한다.

검색 방식, 답변에 표시할 참고 범위, 안전 질문 분류와 사용자 피드백 반영 방식은 설계 단계에서 구체화한다.
