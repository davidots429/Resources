---
title: 용어 사전
---

이 페이지는 처음 참여하는 사람이 다른 문서의 짧은 용어를 해석할 때 쓰는 출발점이다. 구현 객체명이나 상태 코드는 설명용 번역만으로 대체하지 않고 [코드북과 테이블 정의](data.md)의 실제 값을 확인한다.[^rd]

| 용어 | 이 프로젝트에서의 뜻 |
| --- | --- |
| 스마트키친 | 조리로봇·주방장비와 운영자의 작업 데이터를 함께 다루는 가정된 조리 환경 |
| 현장 맞춤형 레시피 | 매장·장비·조리량 조건을 반영한 레시피 후보. [승인](ai/recipe-lifecycle.md) 전에는 현장 적용본이 아니다. |
| 권장 조리조건 | 온도·시간 등의 제안값. 장비 명령이나 자동 설정값이 아니다. |
| 조리작업 | 특정 메뉴·배치·장비에서 실제로 수행하는 한 번의 작업 기록 |
| 식사 배치 | 고등어구이 정식처럼 여러 조리작업을 하나의 제공 단위로 연결하는 범위 |
| Mock | 실제 장비 대신 합성 사건을 만드는 시험용 장치 또는 프로그램 |
| fixture | 반복 가능한 시험 입력의 제조사별 표현과 값 묶음 |
| 원천 payload | 수신 당시의 장비·파일 원문. 표준화 후에도 보존한다. |
| 표준 이벤트 | 원천을 프로젝트 공통 필드·단위·코드로 해석한 결과 |
| Finding | 품질 위반이나 검토할 이상을 기록하는 항목 |
| DLQ | 정상 처리에서 격리된 메시지를 조사·재처리할 대기열 |
| 파생 버전 | 원본을 유지한 채 새 규칙이나 늦은 사건으로 다시 계산한 결과 |
| tenant | 매장·조직별 데이터 접근 범위를 나누는 단위 |
| RD / SRS / DCD | 요구사항 정의서 / 요구사항 명세서 / 데이터 수집 정의서 |
| SAD / IA | 시스템 아키텍처 정의서 / 정보구조·화면 정의 |

[^rd]: [RD v0.7](/Resources/foodtech/files/Foodtech_AI_Recipe_Agent_RD_v0.7.docx), 용어와 사용자 정의. 세부 데이터 값의 의미는 [코드북 v0.2](/Resources/foodtech/files/Foodtech_AI_Recipe_Agent_Codebook_v0.2.xlsx)를 따른다.
