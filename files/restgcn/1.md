- 작성일: 2026-09-28
- 대상 데이터셋: METR-LA, PeMSD4
- 평가 단위: 원속도 단위의 유효 target 원소
- 반복: 각 조건당 seed 0, 1, 2의 3회 학습
- 표기: 평균 ± 표본 표준편차(`ddof=1`)
- 범위: 완료된 54개 학습 run과 E=4 체크포인트 6개의 validation-only 전문화 진단

## 1. 결론 요약

현재 결과에서 가장 좋은 평균 예측 성능을 보인 모델은 **common20 입력 + Node+Channel LayerNorm + 단일 공유 공간 투영**이다. E=4 Receiver MoE는 동일한 입력, 정규화, 채널 구조에서 단일 투영보다 METR-LA overall MAE가 0.0073, PeMSD4가 0.0007 높았다. 세 seed의 방향도 섞여 있으므로 MoE의 평균 성능 향상은 관찰되지 않았다.

초기 제안 모델의 부진은 MoE만의 문제가 아니었다. **Channel-only LayerNorm 패키지**가 가장 큰 성능 저하 요인이었다. speed1 조건에서 이를 Node+Channel 방식으로 바꾸자 overall MAE가 METR-LA에서 10.12%, PeMSD4에서 9.75% 감소했고, 두 데이터셋 모두 adapted baseline을 넘어섰다. 다만 이 실험은 정규화 통계 축과 affine 파라미터 구조를 함께 변경했으므로 개선분을 통계 축 하나의 효과로만 해석할 수 없다.

common20 특징은 정규화 구조를 맞춘 뒤 두 데이터셋에서 추가 이득을 제공했다. 최종 단일 투영 모델은 speed1 adapted baseline 대비 METR-LA overall/H12 MAE를 4.39%/7.82%, PeMSD4를 6.68%/9.94% 낮췄다.

라우터는 붕괴하지 않았다. 모든 seed에서 네 Expert가 모두 사용되었고, 라우팅을 고정하거나 Expert를 순환 교체하면 validation MAE가 악화되었다. 따라서 라우팅은 입력에 따라 실제 계산 경로를 바꾼다. 그러나 이 동작은 단일 투영보다 좋은 평균 test MAE로 이어지지 않았고, 특히 METR-LA에서는 seed 간 센서별 Expert 역할의 재현성이 낮았다. 현재 근거는 **“라우팅이 작동한다”**까지이며 **“MoE가 평균 예측 성능을 향상한다”**는 결론을 지지하지 않는다.

## 2. 실험 질문

실험은 다음 질문을 순서대로 분리했다.

1. 초기 RE-STGCN이 speed1 adapted baseline보다 좋은가?
2. 성능 차이는 입력 특징, Receiver Expert, 정규화·dropout·채널 구조 중 어디에서 발생하는가?
3. E=4가 E=1 또는 단일 공유 투영보다 좋은가?
4. Load-balancing loss가 예측 성능과 Expert 사용 균형에 어떤 영향을 주는가?
5. 입력과 정규화를 완전히 통제했을 때 E=4 Receiver MoE의 순수한 효과는 무엇인가?
6. 평균 성능 이득이 없더라도 Expert가 서로 다른 입력에 반응하고 예측에 기여하는가?

## 3. 공통 실험 조건

| 항목 | 설정 |
|---|---|
| 예측 문제 | 과거 12 step으로 미래 12 step 직접 예측, 5분 간격 |
| 데이터셋 | METR-LA와 PeMSD4를 각각 독립 학습·평가 |
| 그래프 | 데이터셋별 full weighted undirected graph, Chebyshev 3항 |
| 주 backbone | T-S-T 2개 block, 채널 `[64,32,64]`, `[64,32,128]`, direct H12 head |
| 학습 | Adam, lr `1e-3`, weight decay 0, CosineAnnealingLR `T_max=50` |
| 배치 | physical batch 32, gradient accumulation 1, AMP |
| 반복 | seed 0/1/2 |
| 주 지표 | overall MAE, horizon 12 MAE |
| 지표 계산 | inverse scaling 후 유효 target의 error sum/count |
| 평가 무결성 | 완료 checkpoint별 test split 1회 평가, run identity와 artifact hash 검증 |

모든 직접 비교는 데이터셋별 동일 split, graph, scaler, 결측 처리, optimizer와 출력 head를 공유했다. 아래 표에서 입력 또는 normalization package가 다른 행은 원인 분리 과정의 결과이며, 그 차이를 Receiver MoE의 단독 효과로 해석하지 않는다.

## 4. 모델 변형 정의

| 약칭 | 입력 | 공간 연산 | 정규화·dropout | Expert 설정 |
|---|---|---|---|---|
| Adapted | speed1 | 단일 STGCN 공간 투영 | Node+Channel LN, head 직전 dropout 0.5 | 없음 |
| Initial E4 | common20 | Receiver Expert | Channel-only LN, block dropout 0.1 | E=4, top-1 |
| Controlled | common20 | 단일 공유 투영 | Channel-only LN, block dropout 0.1 | 없음 |
| E1 | common20 | Receiver 경로의 단일 Expert | Channel-only LN, block dropout 0.1 | E=1 |
| E4 no-LB | common20 | Receiver Expert | Channel-only LN, block dropout 0.1 | E=4, load balance 제거 |
| Speed1 backbone | speed1 | 단일 공유 투영 | Channel-only LN, block dropout 0.1 | 없음 |
| Speed1 N+C | speed1 | 단일 공유 투영 | Node+Channel LN package | 없음 |
| Common20 N+C Control | common20 | 단일 공유 투영 | Node+Channel LN package | 없음 |
| Common20 N+C E4 | common20 | Receiver Expert | Node+Channel LN package | E=4, top-1 |

`common20`은 z-score 속도 1D, 하루 288개 time-slot embedding 16D, 요일 embedding 2D, observed mask 1D를 연결한 입력이다.

## 6. 원인 분리 과정

### 6.1 초기 비교: 제안 모델은 baseline보다 낮은 성능

초기 E4 proposed는 adapted baseline 대비 다음만큼 MAE가 높았다.

| 데이터셋 | Overall 차이 | H12 차이 |
|---|---:|---:|
| METR-LA | +0.199509 (+6.24%) | +0.339628 (+9.05%) |
| PeMSD4 | +0.056816 (+3.49%) | +0.133596 (+6.61%) |

이 비교에는 입력 차원, normalization package, dropout 위치와 공간 연산 차이가 함께 들어 있으므로 초기 결과만으로 MoE를 원인으로 지목할 수 없었다.

### 6.2 단일 투영 및 E=1: 초기 차이의 대부분은 MoE 외부에도 존재

common20 Channel-only 조건에서 single projection과 E=1 Receiver는 거의 같은 결과를 냈다. E4도 두 조건을 뚜렷하게 이기지 못했다. 따라서 초기 성능 하락은 “Expert 수가 4여서”만 발생한 것이 아니며, 공통 backbone package를 먼저 조사할 필요가 있었다.

### 6.3 Load balancing 제거: 균형은 개선하지만 정확도 효과는 불명확

load-balancing을 제거한 E4는 기존 E4보다 평균 MAE가 아주 조금 낮았지만 seed별 방향은 일관되지 않았다.

| 데이터셋 | no-LB − with-LB Overall | no-LB − with-LB H12 |
|---|---:|---:|
| METR-LA | -0.003793 (-0.11%) | -0.012135 (-0.30%) |
| PeMSD4 | -0.004087 (-0.24%) | -0.005744 (-0.27%) |

반면 best-validation epoch의 평균 normalized routing entropy는 load balancing 사용 시 METR-LA 약 0.965, PeMSD4 약 0.995였고, 제거 시 각각 약 0.741, 0.682로 낮아졌다. 보조 손실은 Expert 독점 억제라는 운영 목적에는 효과가 있었지만, 현재 실험에서는 예측 정확도 향상을 입증하지 못했다.

### 6.4 Speed1 backbone: common20 입력이 성능 저하 원인은 아님

proposed backbone에서 입력을 speed1으로 줄였을 때 Channel-only 조건의 성능은 오히려 더 나빠졌다. common20 controlled 대비 speed1 backbone의 overall MAE는 METR-LA에서 약 0.159, PeMSD4에서 약 0.099 높았다. 시간·요일·mask 특징 자체가 초기 격차의 원인은 아니며, 두 데이터셋에서 유용한 정보를 제공할 가능성이 확인되었다.

### 6.5 Normalization package: 가장 큰 성능 변화

speed1 single-projection 조건에서 Channel-only package를 Node+Channel package로 교체한 결과는 다음과 같다.

| 데이터셋 | Overall 개선 | H12 개선 | Adapted 대비 Overall | Adapted 대비 H12 |
|---|---:|---:|---:|---:|
| METR-LA | -0.357938 (-10.12%) | -0.699752 (-15.84%) | -0.020431 (-0.64%) | -0.033744 (-0.90%) |
| PeMSD4 | -0.173597 (-9.75%) | -0.354160 (-15.05%) | -0.018601 (-1.14%) | -0.021761 (-1.08%) |

세 seed와 모든 horizon에서 Node+Channel 조건이 adapted baseline보다 낮은 MAE를 기록했다. 다만 이 package는 통계 축뿐 아니라 affine 구조도 변경한다. Channel-only affine은 두 block을 합해 384개 파라미터지만 Node+Channel affine은 노드별 파라미터를 포함하여 METR-LA 79,488개, PeMSD4 117,888개다. 그러므로 이 결과는 **Node+Channel package의 효과**이며, 통계 축 하나의 인과 효과로 축소하면 안 된다.

### 6.6 최종 직접 비교: common20 Node+Channel single projection 대 E=4 Receiver

입력, normalization package, backbone, graph, head, 학습 조건을 맞춘 최종 비교는 다음과 같다.

| 데이터셋 | 지표 | Single projection | E=4 Receiver | E4 − Control |
|---|---|---:|---:|---:|
| METR-LA | Overall MAE | 3.058362 | 3.065634 | +0.007272 (+0.24%) |
| METR-LA | H12 MAE | 3.458749 | 3.466871 | +0.008122 (+0.23%) |
| PeMSD4 | Overall MAE | 1.517752 | 1.518444 | +0.000692 (+0.05%) |
| PeMSD4 | H12 MAE | 1.820644 | 1.823005 | +0.002360 (+0.13%) |

METR-LA에서는 E4가 H1에서만 평균적으로 우세했고, PeMSD4에서는 H1~H5에서 아주 작은 이득을 보인 뒤 H6~H12에서 불리했다. 전체 및 H12 기준으로는 single projection이 두 데이터셋 모두 더 좋았다. 차이가 작고 seed별 부호가 섞여 있으므로 E4가 본질적으로 해롭거나 두 모델이 통계적으로 동등하다고 단정할 수도 없다. 확실히 말할 수 있는 것은 **현재 3-seed 평균에서는 E4의 우위가 관찰되지 않았다**는 점이다.

### 6.7 최종 모델군과 adapted baseline 비교

Node+Channel common20 모델은 MoE 여부와 관계없이 adapted speed1 baseline보다 좋았다.

| 데이터셋 | 모델 | Overall 변화 | H12 변화 |
|---|---|---:|---:|
| METR-LA | Single projection | -4.39% | -7.82% |
| METR-LA | E4 Receiver | -4.16% | -7.61% |
| PeMSD4 | Single projection | -6.68% | -9.94% |
| PeMSD4 | E4 Receiver | -6.64% | -9.82% |

따라서 현재까지 확인된 성능 향상의 중심은 common20 특징과 Node+Channel package이며, Receiver MoE의 평균 성능 기여는 확인되지 않았다.

## 7. E=4 Receiver 전문화 진단

최종 E4의 best checkpoint 6개를 validation split에서만 분석했다. test split은 이 진단에 사용하지 않았다. 저장된 validation MAE와 재계산 결과의 최대 절대 차이는 METR-LA `2.63e-7`, PeMSD4 `0`이었다.

### 7.1 라우터 사용 상태

| 지표 | METR-LA | PeMSD4 |
|---|---:|---:|
| Dead Expert 수 | 모든 seed에서 0 | 모든 seed에서 0 |
| Global normalized entropy | 0.981~0.996 | 0.989~0.996 |
| 평균 top-1 확률 | 0.340~0.437 | 0.385~0.427 |
| 평균 top1−top2 margin | 0.066~0.139 | 0.121~0.152 |
| Sensor NMI | 0.061~0.096 | 0.107~0.175 |
| Target-slot NMI | 0.228~0.274 | 0.174~0.260 |
| 센서별 dominant share 평균 | 0.365~0.427 | 0.425~0.464 |

모든 Expert가 사용되었고 전역 부하는 거의 균등했다. Expert 선택은 센서 ID보다 예측 target slot과 더 강하게 연관되었다. 이는 라우터가 고정 센서 분할보다 시간 조건에 더 반응했음을 시사하지만, NMI는 인과관계를 증명하지 않는다.

### 7.2 seed 간 역할 재현성

Expert label을 센서 선택 프로필로 정렬한 뒤 dominant assignment를 비교했다.

| 데이터셋 | 세 seed 만장일치 센서 비율 | seed pair 평균 일치율 |
|---|---:|---:|
| METR-LA | 11.6% | 36.6% |
| PeMSD4 | 55.0% | 67.2% |

PeMSD4에서는 일정 수준의 센서별 역할 재현성이 나타났지만 METR-LA에서는 낮았다. 현재 결과로는 도시나 센서 유형에 대응하는 안정적인 Expert 의미를 공통적으로 주장하기 어렵다.

### 7.3 Expert 차이와 반사실적 기여

- Expert weight의 pairwise absolute cosine 평균은 METR-LA block별 약 0.114~0.345, PeMSD4 약 0.007~0.072였다.
- 실제 입력에 대한 Expert raw output cosine은 이보다 높았으며, 특히 block 2에서 METR-LA 0.532~0.761, PeMSD4 0.413~0.507이었다. 가중치가 달라도 출력 기능이 상당히 겹칠 수 있음을 보여준다.
- 학습된 라우팅은 모든 seed에서 가장 좋은 단일 고정 Expert보다 validation MAE가 낮았다. 이점 범위는 METR-LA 0.031~0.091, PeMSD4 0.128~0.311이었다.
- Expert를 순환 교체하면 모든 seed에서 MAE가 증가했다. 증가 범위는 METR-LA 0.109~1.098, PeMSD4 0.602~0.977이었다.

이 진단은 라우팅이 단순 장식이 아니며 학습된 Expert-입력 대응이 예측에 영향을 준다는 점을 지지한다. 그러나 고정 Expert 평가는 해당 Expert가 학습 중 보지 못한 라우팅 영역까지 강제로 처리하게 하는 반사실적 실험이다. 따라서 이 결과를 single projection 대비 성능 우위로 해석할 수 없다.

## 8. 종합 해석

1. **초기 proposed의 실패 원인을 MoE로 단정한 가설은 기각되었다.** 입력 차이를 제거해도 Channel-only package의 성능 저하가 유지되었고, Node+Channel package가 대부분의 격차를 회복했다.
2. **common20 입력은 유용했다.** 같은 Node+Channel single-projection 구조에서 speed1보다 common20이 두 데이터셋 모두 더 좋은 결과를 냈다.
3. **Receiver MoE는 정상 작동하지만 평균 정확도 이득은 없었다.** Expert 붕괴가 없고 라우팅의 반사실적 중요성은 확인됐지만, 완전히 통제한 비교에서 single projection을 이기지 못했다.
4. **Load balancing은 기능적 목적과 예측 목적을 구분해야 한다.** 선택 균형과 dead Expert 방지에는 효과가 있었으나 평균 MAE 개선은 확인되지 않았다.
5. **현재 최선의 실용 모델은 common20 Node+Channel single projection이다.** 정확도, 구조 단순성, 해석 비용을 함께 고려하면 이 모델이 후속 연구의 기준선이 된다.
6. **MoE의 남은 연구 가치는 평균 성능보다 조건부 방어 가능성에 있다.** 혼잡, 사건, 급격한 상태 변화 같은 극단 조건에서 single projection보다 오류를 줄이는지 별도 benchmark로 확인할 가치가 있다. 현재 실험은 그 가능성을 입증하지 않았다.

## 9. 한계

- seed가 3개이므로 작은 차이에 대한 통계적 유의성이나 동등성을 주장하기 부족하다.
- Node+Channel 통제는 normalization 통계 축과 node-specific affine을 함께 바꿨다. 두 요인의 기여는 분리되지 않았다.
- 실험 데이터셋은 METR-LA와 PeMSD4 두 개이며, 다른 도시·센서망으로 일반화할 근거는 아직 없다.
- 전문화 진단은 validation-only이며 극단 교통 상태 benchmark가 아니다.
- Expert counterfactual은 학습된 support 밖의 입력을 포함할 수 있고, cyclic replacement는 학습된 대체 정책이 아니라 민감도 시험이다.
- GMM congestion hint, congestion group 평가, 사건·극단 상태 평가, Expert 수 튜닝은 수행하지 않았다.
- 최종 E4와 control의 차이가 매우 작으므로 “MoE가 해롭다” 또는 “두 모델이 동등하다”는 결론도 현재 자료만으로 확정할 수 없다.

## 10. 권장 후속 순서

1. **현재 주 기준선 고정:** common20 + Node+Channel + single projection을 후속 비교의 기본 모델로 사용한다.
2. **극단 조건 평가 설계:** 평균 MAE가 아니라 혼잡·급변·결측·희소 관측 구간에서 E4가 error tail을 줄이는지 평가한다. 평가 기준은 사전에 고정하고 validation에서 설계한 뒤 test는 한 번만 사용한다.
3. **Normalization package 세분화:** 통계 축과 affine 구조를 분리한 실험이 필요하면 `N×C statistics + channel-shared affine` 같은 중간 통제를 추가한다.
4. **MoE를 계속 연구할 경우 최소 비교:** 같은 checkpoint 정책 아래 E=1/2/4, load-balance on/off, Expert output 유사도와 tail metric을 함께 기록한다.
5. **작은 차이를 논문 주장으로 사용할 경우:** seed 5회 이상 또는 사전 정의한 paired 검정을 사용하고, 평균 성능·분산·조건부 성능을 분리해 보고한다.
6. **현재 단계의 주장 제한:** “Receiver 라우팅은 비퇴화되고 입력 의존적이지만, 평균 test MAE에서 단일 투영의 우위를 넘지 못했다”를 연구 결과의 정확한 표현으로 사용한다.

## 12. 최종 판단

현재 실험이 가장 강하게 지지하는 결론은 다음과 같다.

> common20 시간 특징과 Node+Channel normalization package는 두 데이터셋에서 예측 성능을 일관되게 개선했다. Receiver E=4 라우팅은 Expert 붕괴 없이 입력 의존적으로 작동하고 예측 경로에 실질적인 영향을 주었지만, 동일 조건의 단일 공유 공간 투영보다 평균 overall/H12 MAE를 개선하지 못했다.

따라서 모델 선택의 현재 기본값은 single projection이며, RE-STGCN의 후속 가치는 평균 성능 경쟁보다 극단 상태에서의 조건부 성능 방어와 재현 가능한 전문화 여부를 검증하는 데 있다.
